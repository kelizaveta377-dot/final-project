Это простой микросервис, предназначенный для хранения и поиска информации о книгах в учебной среде. Он позволяет получать список всех книг, искать книги по идентификатору (ID) и фильтровать их по имени автора. 

Предназначен для студентов, изучающих Python, FastAPI и DevOps; разработчиков, осваивающих инфраструктуру проектов.

Создаем окружение и устанавливаем зависимости 

1. Переходим в папку
2. Создаем виртуальное окружение на базе Python 3.12

python3.12 -m venv .venv && source .venv/bin/activate

3. Устанавливаем необходимые библиотеки 

pip install --break-system-packages -r requirements.txt

4. Для запуска тестов дополнительно установим 

bash pip install pytest httpx

Запускаем приложение и открываем /docs

1. ./run.sh
2. Команда запуска без флага --reload для обычной работы приложения

uvicorn main:app --host 127.0.0.1 --port 8000

Переменные окружения используемые в сервисе

APP_NAME - Название сервиса - Book Catalog Service (Значение по умолчанию)
APP_AUTHOR - Имя разработчика - Unknown (Значение по умолчанию)
APP_VERSION - 	Версия приложения - 1.0.0 (Значение по умолчанию)
APP_PORT - 8000 (Значение по умолчанию)

Проверяем /health, /version и смотрим логи

1. Проверка работоспособности 
curl http://127.0.0.1:8000/health (должен вернуть {"status":"ok"})

2. Версия приложения 
curl http://127.0.0.1:8000/version (должен вернуть "version": "1.0.0")

3. Логи событий 
Все основные действия пользователя выводятся в консоль сервера функцией print(). Например, [LOG] Запрошена книга с ID: .... Чтобы увидеть логи, необходимо открыть окно терминала, где запущен сервер (./run.sh), во время выполнения запросов.

Запускаем тесты 

1. Локальные тесты запускаются с помощью Pytest

pytest -v

2. Автоматическая проверка настроена через GitHub Actions. Результаты можно посмотреть во вкладке Actions репозитория.
